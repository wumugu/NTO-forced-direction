# C. Вынужденная направленность

Решение задачи **«Вынужденная направленность»** из НТО 2026/27, этап 1, направление **«Технологии беспроводной связи»**.

## Идея

В задаче нужно найти долю направлений, для которых сигнал не выйдет за пределы двора.

Есть два механизма блокировки:

1. сигнал непосредственно попадает в здание **Б**, которое полностью поглощает нужные частоты;
2. сигнал сначала отражается от здания **А**, а после отражения попадает в здание **Б**.

Антенна расположена в точке:

```text
A = (20, 20)
```

### Прямое попадание в Б

Крайние лучи, попадающие в поглощающее здание Б, проходят через его крайние вершины:

```text
(160, 100)
(80, 160)
```

Их углы относительно антенны:

```text
29.744881...°
66.801409...°
```

Поэтому непосредственно закрытая угловая область:

```text
37.056528...°
```

### Отражение от А и последующее попадание в Б

Релевантная отражающая грань здания А задаётся точками:

```text
(-40, 100)
(0, 200)
```

Чтобы учесть отражение, дом Б мысленно отражается относительно этой прямой.

Для вершины `(95, 180)` отражённая точка имеет координаты:

```text
(-82.586206..., 251.034482...)
```

Направление от антенны на эту точку:

```text
113.942649...°
```

Вторая граница рассматриваемого диапазона проходит через точку:

```text
(-40, 100)
```

Её угол:

```text
126.869897...°
```

Дополнительная заблокированная область:

```text
12.927248...°
```

### Итог

Полная заблокированная угловая область:

```text
37.056528... + 12.927248...
= 49.983776...°
```

Доля от полного оборота:

```text
49.983776 / 360 * 100
= 13.8843...%
```

Ответ с требуемой точностью:

```text
13.88
```

## Запуск

```bash
python C_forced_direction.py
```

Программа выводит:

```text
13.88
```

## Используемые средства

- Python 3
- `math.atan2`
- геометрическое отражение точки относительно прямой
- вычисление углов между лучами
